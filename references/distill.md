# DISTILL：科研语料库与可核验的 Writing DNA

## 1. 语料选择
- SCI 按 `Introduction`、`Discussion` 等章节建子库；国家自然科学基金按 `立项依据`、`研究内容`、`研究方案` 建子库。分开训练/总结，不合并统计。
- 优先同行评审正式发表版本；明确年份、期刊、DOI、领域相近程度及是否有勘误。基金申请书仅使用有合法处理权的材料。
- 建议每个子库收集约 20 篇同体裁的可读取完整资料，用于多样本归纳；这只是项目初期的工作建议，**不是经过统计学验证的最低样本量或稳定性阈值**。若仅有 5–10 篇，标明所有结论为探索性。
- 不因期刊影响因子或项目中标就推定每句话都正确。选例必须同时检查事实、论证和表述。
- 访问级别逐篇登记：`全文+图表` / `正文但缺图表或补充` / `部分正文` / `仅摘要` / `不可访问`。不把摘要算作完整样本。

## 2. 执行方法
1. 将用户授权的 PDF/DOCX/MD/TXT 放于用户项目本地 `corpus/<体裁>/<章节>/`（勿放入 Skill 安装包或公开 Git 仓库）。
2. 使用 `python scripts/corpus_audit.py --corpus <目录> --out <输出目录>` 清点文件及自动提取情况。扫描 PDF、公式、表格、复杂双栏排版可能失真，须打开原始页面核对。
3. 排除重复版本，生成 `_meta` 记录：ID、标题、年份、DOI、来源、章节、访问级别、提取警告、正文长度、是否相似/重复。不能凭文件名推断被引用内容。
4. 对每篇做**篇章功能标注**：研究背景/已知事实/争议/明确缺口/问题和目标，或结果解释/同异比较/机制与备选解释/局限。
5. 从同类文章归纳语言规律：术语、衔接逻辑、主动/被动语态的适用场景、比较语句、引用方式、克制判断和缩写策略。统计只能发现候选规律，须抽样核验其上下文。
6. 把高价值规则写成 `规则 → 来源 ID + 章节/页码或可定位段落 → 适用条件 → 反例/例外 → 可信等级（充分/有限/探索）`。不要将研究发现或某作者特有的句子写成模板。
7. 将结果填写 `templates/Writing-DNA.template.md`，按课程/领域及文稿类型保存。然后从未参与归纳的至少 2 篇新材料核验规则是否普遍适用；若没有留出验证样本，标为“未外部验证”。

## 3. 科研写作六项核查维度
| 核查维度 | 分析内容 | 常见误区 |
|---|---|---|
| 学术语言 | 结果报告、比较对象、限定词、时态和专业术语 | 高频词不等于更准确的表达 |
| 论证结构 | 段落任务、主张与证据的衔接、章节过渡 | 强加固定四段结构 |
| 科学问题 | 已有认识、研究争议与明确可检验的问题 | 仅凭论文写法推断研究空白真实存在 |
| 证据组织 | 试验数据、同行评审文献、反例与局限的安排 | 引用格式正确不等于文献真实 |
| 推断强度 | 相关与因果、机制解释、竞争假设与结论限制 | 将原作者的科学结论照搬到新项目 |
| 图文一致性 | 图表、变量、单位、显著性标记与正文对应 | 以固定排版习惯取代期刊和基金要求 |

## 4. 产物与存储
只把生成的风格规范及非侵权的最短示例写入项目 `Writing-DNA.md`。原始受版权保护语料仅存用户授权目录。报告应能追踪每条判断来自哪些原文；没有原文定位的规则降为“临时偏好”，不当作已蒸馏规律。
