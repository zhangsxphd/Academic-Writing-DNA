# SCI 论文写作与修改 · 分章节规则

## Introduction
- 开始于与本文研究尺度相符的具体问题。根据可核实文献描述已知规律；跨学科或跨实验条件外推须加限定。
- 从已有研究的结果或争议推导出**具体尚未回答的问题**，不要用“研究很少”替代检索结论。
- 最后一段对接试验设计可检验的目标/假设。若没有设计区分机制，仅写关联性目标，不宣称“阐明机制”。
- 引用只使用真实可核的文献。明确区分正文已读与仅摘要。

## Materials and methods
- 交代研究地点/条件、实验单元、因素与处理水平、随机化、重复次数（独立/技术重复分开）、采样时点和层位、测量方法、质量控制、统计模型与多重比较方法。
- 检查试验设计支持的推断尺度：盆栽≠大田、单一地点≠区域普适；处理间若存在混杂，不能按完整析因设计解释。
- 对重要缺项标为 `[需作者补充：...]`，不代写仪器型号、软件版本或统计方案。

## Results
- 每条关键表述应呈现 `变量 + 处理/组别 + 比较对象 + 方向/幅度 + 单位 + 显著性（若确已检验）`，但不强制每句话重复全部要素。
- 分清原始值、差值、百分比与百分比百分点；百分变化需核对分母。
- 保留 `n`、均值±误差含义（SD/SE/CI）、字母标记、p值、图表引用一致性。
- 主要用描述性语言；没有独立机理证据时，不把微生物组或网络相关变化描述为已验证的因果途径。

## Discussion
- 按结果主题组织：实际观察 → 与文献比较 → 可支持的机制解释 → 备选解释/不确定性 → 学术意义。
- 机制强度标注为 `直接测量支持` / `间接证据支持` / `尚未验证的假设`。未测根系、酶活、气体、微生物生长等指标，不能声称机制已经确定。
- 讨论局限应与研究设计或证据缺口相联系，不写空洞万能句。
- 不能用“与其他研究一致”替代具体的条件、效应方向及差异解释。

## Abstract / Conclusion
- 全部数字均应能回溯到原始 Results；不能在结论中引入未分析的新数据。
- 准确限定实验类型、样本尺度、处理条件和效果适用范围；避免超出研究设计的推广与“首次”主张。

## 文体提醒
- 英文科技论文按目标期刊惯例使用必要的被动句和标准术语；不要以中文“去 AI 味”清单处理英文。
- 可缩短冗长句，但不能牺牲限定、比较对象或来源说明。避免空泛开头、反复总述和不自然的宣传语。
- 所有增添的引文、数据、机制句必须指向本次已提供或经过查证的来源；不因 Writing DNA 的“类似范文”就自动添加。
